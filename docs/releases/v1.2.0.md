# Hammond Modern v1.2.0

## Änderungen

- Vue 3 und Buefy 3 ersetzen die frühere Weboberfläche technisch. Vue Router und Vuex unterstützen Vue 3. Vite baut die Anwendung, Vitest führt die Frontend-Tests aus. Das Verbrauchsdiagramm verwendet Chart.js 4.
- Die Ersteinrichtung endet, sobald das erste Administratorkonto besteht. Fahrzeug- und Dateizugriffe berücksichtigen Freigaben und Eigentum.
- Browser-Sitzungen werden serverseitig gespeichert und lassen sich widerrufen. Ausgelieferte Anhänge benötigen eine Anmeldung und die passenden Rechte.
- Automatische Backups verwenden das portable ZIP-Format und enthalten auch die Anhänge. Ältere kompatible portable Backups lassen sich weiterhin importieren.

## Update von v1.1.11

1. `/config`, `/assets` und die bisherige Containerkonfiguration getrennt vom laufenden Container sichern.
2. Bestehenden Compose-Projektnamen und dieselben Daten-Mounts weiterverwenden. Das Image auf `skoun181/hammond-modern:1.2.0` setzen.
3. Den vorhandenen Stable-Stack mit `docker compose pull` und `docker compose up -d` aktualisieren.
4. Mit dem vorhandenen Konto erneut anmelden. Bei HTTPS am Reverse Proxy `SESSION_COOKIE_SECURE=1` setzen und den externen Host durchreichen.

`JWT_SECRET` dient der Absicherung neuer Sitzungen und muss mindestens 32 Bytes lang sein. Vorhandene ausreichend lange Schlüssel können beibehalten werden. Für einen Rückstieg die vor dem Update angelegte Kopie der Daten und Containerkonfiguration verwenden.

Docker Hub liefert `skoun181/hammond-modern:1.2.0` für Linux AMD64.
