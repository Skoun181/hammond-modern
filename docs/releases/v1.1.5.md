# Hammond Modern v1.1.5

**Neue Stable-Version** von Hammond Modern auf Grundlage des bisherigen Develop-Branches.

## Highlights

### 🧰 Datenübernahme aus dem Original-Hammond
- Neuer Migrationsassistent unter **Datenimport → Hammond-Migration starten**
- Upload der originalen `hammond.db` als konsistente SQLite-Sicherung (maximal 50 MB)
- Vorschau der gefundenen Fahrzeuge, Tankungen und Ausgaben vor der Übernahme
- Automatische Gruppierung mehrfach vorhandener, identischer Fahrzeuge unter Beibehaltung ihrer Historie
- Auswahl der zu importierenden Fahrzeuge per Checkbox; standardmäßig keine Vorauswahl
- Schutz gegen doppelte Tankungen und Ausgaben beim wiederholten Import
- Temporäres, schreibgeschütztes Einlesen der Quelldatei und transaktionale Übernahme

### 📱 Oberfläche und Fahrzeugdetails
- Überarbeitete Desktop- und Smartphone-Darstellung
- Gut lesbare Dark-Mode-Tabellen inklusive Hover- und Mobilzuständen
- Verbesserte Aktionsbuttons, Formularlayout und Dropdown-Menüs
- Lokalisierte Währungsbeträge, auf eine Nachkommastelle gerundete Literwerte
- Neu gestaltete Import-Startseite und Importvorschau

### 🚗 Dashboard und Wartungsplanung
- Wartungstermine für HU/TÜV, Service und Inspektionen nach Datum und/oder Kilometerstand
- Anstehende Wartungen und Kostenübersichten im Dashboard
- Verbesserte Kostenstatistiken und Fahrzeugauswahl beim Hinzufügen von Tankungen
- Quick Entries aus Navigation und Benutzeroberfläche entfernt

## Installation
Die Anwendung wird lokal aus dem Quellcode per Docker Compose gebaut. Für eine neue Installation:

```bash
git clone --branch stable/hammond-modern https://github.com/Skoun181/hammond-modern.git
cd hammond-modern
printf 'JWT_SECRET=%s\n' "$(openssl rand -hex 32)" > .env
chmod 600 .env
mkdir -p data/config data/assets
docker compose -f compose.test.yml up -d --build
```

Danach `http://SERVER-IP:3006` öffnen und Administrator sowie Einstellungen einrichten.

## Upgrade von einer älteren Version
Vorher `.env`, `data/config` und `data/assets` sichern (SQLite-Datenbank nur im konsistenten Zustand kopieren).

```bash
git fetch origin --tags
git switch stable/hammond-modern
git pull --ff-only origin stable/hammond-modern
docker compose -f compose.test.yml up -d --build
```

Ein älterer lokal per Force-Reset bearbeiteter Stable-Checkout kann für `git pull --ff-only` einen erneuten Checkout benötigen. Persönliche Daten und `.env` keinesfalls löschen.

## So migrierst du deine Daten
1. Original-Hammond stoppen oder konsistente SQLite-Sicherung anlegen.
2. `hammond.db` aus dem Original-`/config`-Verzeichnis kopieren.
3. In Hammond Modern **Datenimport → Hammond-Migration starten** öffnen.
4. Datei auswählen, Vorschau prüfen, zusammengefasste Fahrzeuge kontrollieren.
5. Gewünschte Fahrzeuge per Checkbox auswählen und erst dann den Import bestätigen.
6. Anschließend Tankungen, Kosten und Kilometerstände im neuen System vergleichen.

## Wichtige Einschränkungen
- **Die Migrationsvorschau und Zusammenfassung doppelter Fahrzeuge wurden praktisch geprüft; ein vollständiger Import ist noch nicht abschließend getestet.** Erst mit Sicherungen und nicht-produktiven Kopien testen.
- Konten, Passwörter, Freigaben, Fahrerzuordnungen, Anhänge und Rechnungsdateien werden nicht übernommen.
- Die Foto-OCR für Tankbelege ist **experimentell und nicht zuverlässig**. Daten bitte manuell kontrollieren.
- Keine automatischen Wartungsbenachrichtigungen.
- Kein vollständiger Sicherheits-/Produktionstest.
