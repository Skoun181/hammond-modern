# Hammond Modern v1.1.11 – Home Assistant

## Neu
- Home-Assistant-API zum **lesenden** Abruf offener Wartungen (`GET /api/integrations/homeassistant/maintenance`). Die API liefert Fälligkeiten, Kilometerstände und eine Zusammenfassung.
- Eigenen Home-Assistant-API-Schlüssel in Hammond über **Home Assistant → Schlüssel erstellen** ausstellen, erneuern oder widerrufen. Der Schlüssel wird nur als Hash gespeichert; weder Login-Passwort noch `JWT_SECRET` werden für den REST-Zugriff verwendet.
- Native Home-Assistant-REST-Sensoren (ohne Custom Integration) mit Zugriff über `/config/secrets.yaml`; Konfigurationsbeispiel in `homeassistant/hammond_modern.yaml` und Anleitung in `docs/HOME-ASSISTANT-REST.md`.
- Optionale experimentelle Home-Assistant-Custom-Integration mit Wartungssensoren unter `custom_components/hammond_modern` bleibt verfügbar.
- API nur für aktive Benutzer und berechtigte Fahrzeuge; API-Key wird nicht in portable ZIP-Backups übernommen. Bei Restore neue Schlüssel erzeugen.

## Updatehinweise
- Vor dem Update bestehende Datenverzeichnisse `/config` und `/assets` sowie Container-Einstellungen sichern. Vorhandene Mounts, `JWT_SECRET`, IP und Netzwerk unverändert lassen.
- Bei Aktualisierung von 1.1.10 wird die Datenbank beim Start um die Home-Assistant-Key-Tabelle ergänzt. Ein Downgrade nur mit einer vor dem Update angefertigten kompatiblen Sicherung planen.
- Nicht die Stable- und Develop-Container gemeinsam mit demselben persistenten Datenverzeichnis starten.
- Home Assistant muss den Hammond-Container über Netzwerk erreichen können. Ein Token in `secrets.yaml` ersetzt keine Firewall- oder Routing-Freigabe.

Docker Hub: `skoun181/hammond-modern:1.1.11` (linux/amd64), alternativ `latest`.

```bash
docker compose pull
docker compose up -d
```
