# Hammond Modern v1.1.8 – Automatische Reifenlaufleistung und E5/E10

## Neu
- Montage-Kilometerstand und Wechseldatum pro Reifen erfassen. Die aktuelle zusätzliche Laufleistung ergibt sich aus der Differenz zum höchsten seit Montage erfassten Kilometerstand aus Tankungen.
- Bei der Abmontage wird die Laufleistung mit dem tatsächlich eingegebenen Tacho-Stand abgeschlossen und gespeichert. Bei erneuter Montage zählt der Reifen auf seiner bisherigen Laufleistung weiter. Eingelagerte Reifen und Ersatzräder sammeln keine automatischen Kilometer.
- Gemeinsamer Saisonwechsel für bis zu vier Radpositionen: Kilometerstand einmal eingeben, bisherige Reifen einlagern und andere Reifen des Fahrzeugs montieren. Änderungen erfolgen in einer Transaktion.
- Anzeige der laufenden Reifen-Kilometer, des Montage-Kilometerstands, des Montagedatums und des berücksichtigten Fahrzeugstands.
- Vorhandene montierte Reifen ohne bekannten Startstand benötigen eine einmalige Eingabe über Bearbeiten; frühere Kilometer werden nicht erfunden. Meilen-Tankungen werden nicht mit Kilometerangaben vermischt.
- Kraftstofftyp Petrol heißt Super E5. Super E10 ist zusätzlich auswählbar; bestehende Enum-IDs bleiben unverändert. E5/E10 stehen bei Benzinfahrzeugen auch als Vorschläge im Tankformular bereit.

## Backup und Update
Die neue Tabelle mit den Montageintervallen wird beim Start automatisch angelegt und in portablen ZIP-Backups berücksichtigt. Ältere kompatible Backups bleiben importierbar; sie enthalten jedoch keine aktiven Montageintervalle. Vor dem Update /config, /assets und .env extern sichern. Bei einem Downgrade eine vor dem Update angelegte kompatible Sicherung verwenden. Bestehende Mounts, JWT_SECRET, Netzwerk und IP beibehalten.

Docker Hub: `skoun181/hammond-modern:1.1.8` (linux/amd64), alternativ `latest`.
```bash
docker pull skoun181/hammond-modern:1.1.8
```
Bei Compose den Image-Tag anpassen, dann `docker compose pull && docker compose up -d`. Git-Tag: `v1.1.8`.
