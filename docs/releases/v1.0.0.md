# Hammond Modern v1.0.0

**Erste getestete Stable-Version** von Hammond Modern.

Git-Commit: `5477bb1a5199f44f6ca3ddf41b6a171344b18d9d` auf `stable/hammond-modern`.

## Funktionen
- Modernisierte Oberfläche mit deutschem Bedienkonzept und Dark-/Light-Modus
- Fahrzeugverwaltung und Modellvorschläge
- Tankungen mit Fahrerzuordnung und Tankstellensuche per PLZ
- Werkstattkosten einschließlich Rechnungsanhängen
- Fahrzeug-Dashboard mit Verbrauch und Kostenübersicht

## Installation
Auf Basis des Stable-Branches mit `compose.test.yml` und lokalem Docker-Build. Details stehen in der README.

## Hinweis
Getestete Kernabläufe auf einer privaten Debian-LXC-Instanz; kein offizielles Image oder umfassender Produktions-/Sicherheitstest.
