# Hammond Modern v1.1.10 – Erweiterte Finanzierung

## Neu
- Optionale einmalige Anzahlung mit historischem Zahlungsdatum. Automatische Erfassung als Fahrzeugausgabe oder ausdrückliche Kennzeichnung als bereits erfasst. Die Anzahlung verändert weder Ratenanzahl noch bestehende Buchungen.
- Nettodarlehensbetrag, vertraglicher Sollzins und effektiver Jahreszins. Bestehende Finanzierungspläne können ergänzt werden. Eine einmal gespeicherte Anzahlung bleibt festgeschrieben; Vertragszinsen sind bearbeitbar.
- Geschätzte Restschuld mit centgenauer monatlicher Zinsrundung. Optional abweichender monatlicher Berechnungszins und Zinsanteil der ersten Rate aus dem Bank-Tilgungsplan; Standard ist Sollzins / 12. Effektivzins bleibt eine Vertragsangabe. Kein bestätigter Bankrestsaldo, keine Berücksichtigung von Sondertilgungen oder gesonderten Gebühren.
- Klar getrennte Anzeige: ausstehende Zahlungen inklusive zukünftiger Zinsen und Schlussrate gegenüber der geschätzten aktuellen Kreditrestschuld. Zusammenfassung der aktiven Pläne je Währung; fehlende Darlehens- oder Zinsdaten werden angezeigt.
- Gesamte geplante Zahlungen inklusive Anzahlung und Differenz zwischen Ratensumme und Nettodarlehen.
- Alle bisherigen Funktionen zur automatischen Erfassung der monatlichen Raten bleiben erhalten.

## Update und Backup
Die neuen Tabellen für Finanzierungsdetails und Berechnungswerte werden beim Start automatisch angelegt. Sie sind Bestandteil des ZIP-Backups; ältere kompatible ZIPs können importiert werden, enthalten jedoch diese neuen Details nicht. Vor dem Update /config, /assets und die Container-Konfiguration extern sichern. Bestehende Mounts, JWT_SECRET, Netzwerk und IP beibehalten. Beim Nachtragen einer bereits verbuchten Anzahlung die entsprechende Checkbox nutzen.

Docker Hub: `skoun181/hammond-modern:1.1.10` (linux/amd64), alternativ `latest`.
Bei festem Tag zuerst das Image auf 1.1.10 umstellen.

```bash
docker compose pull
docker compose up -d
```

Git-Tag: `v1.1.10`.
