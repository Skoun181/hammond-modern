# Contributing to hammond-modern / Mitwirken

Deutsch und Englisch sind willkommen. / German and English are welcome.

## Deutsch

Vielen Dank für dein Interesse an hammond-modern!

- [Issues](https://github.com/Skoun181/hammond-modern/issues/new/choose): Fehlerberichte, Funktionswünsche und Verbesserungen.
- [Discussions](https://github.com/Skoun181/hammond-modern/discussions): allgemeine Fragen, Hilfe und erste Ideen.
- [Pull Requests](https://github.com/Skoun181/hammond-modern/pulls): konkrete Änderungsvorschläge am Code oder an der Dokumentation.

Prüfe zuerst, ob bereits ein passendes Issue oder eine Diskussion existiert. Beschreibe Fehler nachvollziehbar und nenne die verwendete Version. Bei größeren Änderungen stimme die Idee möglichst vor der Umsetzung ab.

### Code beitragen

1. Forke das Repository und erstelle einen eigenen Arbeitsbranch auf Basis von `develop/hammond-modern-next`.
2. Halte Änderungen klein und thematisch fokussiert. Beachte den vorhandenen Code-Stil.
3. Führe die für deine Änderung relevanten Tests aus und aktualisiere bei Bedarf die Dokumentation.
4. Erstelle einen Pull Request gegen `develop/hammond-modern-next`, sofern der Maintainer keinen anderen Zielbranch vorgibt. Fülle die Vorlage aus und verlinke zugehörige Issues.

Der Maintainer entscheidet über die Annahme und den Zeitpunkt der Umsetzung. Es gibt keine Garantie für eine Antwort, Umsetzung oder Übernahme.

### Datenschutz und Umgang

Veröffentliche keine Zugangsdaten, Tokens, vollständigen Datenbankdateien oder personenbezogenen Daten. Bitte keine Fahrzeugkennzeichen, VINs, Standortdaten oder Home-Assistant-Zugangsdaten veröffentlichen. Sicherheitsprobleme mit sensiblen Details bitte nicht öffentlich beschreiben; frage den Maintainer zunächst nach einem privaten Meldeweg. Bleibe respektvoll und sachlich.

## English

Thank you for your interest in hammond-modern!

- [Issues](https://github.com/Skoun181/hammond-modern/issues/new/choose): bug reports, feature requests and improvements.
- [Discussions](https://github.com/Skoun181/hammond-modern/discussions): general questions, support and early ideas.
- [Pull requests](https://github.com/Skoun181/hammond-modern/pulls): concrete changes to code or documentation.

Search for existing issues and discussions first. Provide reproducible steps and your version for bug reports. For larger changes, discuss the idea before implementing it.

### Contributing code

1. Fork the repository and create a working branch based on `develop/hammond-modern-next`.
2. Keep changes small and focused, following the existing code style.
3. Run relevant tests and update documentation when needed.
4. Open a pull request targeting `develop/hammond-modern-next` unless the maintainer requests another base branch. Complete the template and link relevant issues.

The maintainer decides which proposals are accepted and when. A response, implementation or merge is not guaranteed.

### Privacy and conduct

Do not publish credentials, tokens, full database files or personal data. Do not publish license plates, VINs, location data or Home Assistant credentials. Do not publicly disclose sensitive security vulnerability details; first ask the maintainer for a private reporting channel. Be respectful and constructive.

## Labels / Labels

Suggested labels for triage / Empfohlene Labels zur Einordnung:

| Label | Meaning / Bedeutung |
| --- | --- |
| `bug` | Bug / Fehler |
| `enhancement` | Feature or improvement / Funktion oder Verbesserung |
| `question` | Question / Frage |
| `documentation` | Documentation / Dokumentation |
| `help wanted` | Help welcome / Hilfe erwünscht |
| `good first issue` | Suitable for newcomers / Für Einsteiger geeignet |
| `planned` | Planned, no guaranteed date / Geplant, ohne festen Termin |
| `wontfix` | Not planned / Nicht vorgesehen |

Labels are assigned by maintainers according to availability and need. / Labels werden vom Maintainer nach Verfügbarkeit und Bedarf vergeben.
